worker 从 `src/cv_agent/runtime/witness/kernel.py` 启动。两份产物里都没有引用旧的运行时路径。

## 4. 迁移前后逐项对照

对照基准是迁移前记录的 `K2_pre_move_binding.json`。哈希方法为：对值做 `json.dumps(value, sort_keys=True, separators=(",", ":"))` 后取 SHA-256。用这个方法从迁移前的产物重新计算，能复现记录里的全部哈希。

| 字段 | hp003_a | hp003_b |
| --- | --- | --- |
| 检出提交 | 相同 | 相同 |
| 入口文件 SHA-256 | 相同 | 相同 |
| 源码模块数（977） | 相同 | 相同 |
| 977 项源码模块的整体哈希 | 相同 | 相同 |
| 原始 subject 哈希 | 相同 | 相同 |
| 执行 subject 哈希 | 相同 | 相同 |
| status / raw_status | 相同 | 相同 |

两份 manifest 中**唯一**变化的字段是 `python_executable`，原因是重建后的 venv 路径不同。每个快照都与它自己迁移前的记录比较，没有拿两个快照互相比较来代替。
